# Paquete de Submission a Directorios — Nebbuler

**Producto:** Nebbuler — Plataforma de membresías para creadores LATAM
**URL:** https://nebbuler.com
**Stack:** Next.js 14 + Supabase + MercadoPago
**Diferenciadores clave:**
1. Pagos en moneda local LATAM (COP, MXN, ARS, CLP, PEN, BRL)
2. 0% comisión los primeros 6 meses
3. Soporte 100% en español
4. Diseñado para 18 países hispanohablantes
5. Alternativa real a Substack/Patreon/Beehiiv para LATAM
