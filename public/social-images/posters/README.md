# Posters para publicar en X (@Nebbuler)

Deja aquí tus imágenes y el robot las publica automáticamente cada día.

## Formatos aceptados
- PNG (recomendado)
- JPG / JPEG
- WEBP

## Tamaño recomendado
- 1200 x 675 px (horizontal 16:9) — ideal para X/Twitter

## Cómo funciona
- El robot revisa esta carpeta cada día a las 14:00 UTC
- Publica las imágenes en orden, una por día
- Cuando termina todas, vuelve a empezar desde la primera
- Si la carpeta está vacía, usa las imágenes automáticas de Nebbuler

## Nombre de los archivos
Cualquier nombre está bien. Ejemplo:
- poster-economistas.png
- banner-0-comision.jpg
- nebbuler-abogados.png
